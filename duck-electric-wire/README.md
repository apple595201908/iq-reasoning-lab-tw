## 📸 遊戲簡介

玩家操控受困於高壓電工廠的「Q 版特工小鴨」，在垂直向下滾動的賽道中精準閃避隨處可見的高壓金屬鋼樑與重型工業機關。只要碰觸兩側高壓電弧壁或任何旋轉電棒，小鴨將瞬間觸電爆散羽毛！

全賽道長度 **33,000px**，以 **110 px/s** 恆定速度前進，全程恰好 **300 秒（5 分鐘整）**。隨時間深入，機關旋轉節奏與時差複雜度逐步拉高，專為「考驗人類神經極限反應」而設計！

## 🎮 核心玩法與操控設計

### 1. 直覺手機觸控優先（Mobile Portrait First）
- **1:1 精密指尖吸附**：手指在螢幕上拖曳到哪，小鴨以 60FPS 平滑微秒跟隨。
- **防止手指遮擋視線**：支援「防遮擋模式（Offset Mode）」，小鴨維持在指尖上方 45px，視野完全清晰。
- **擦彈寬容判定（Graze Leeway）**：小鴨外觀為 36px 圓潤可愛造形，核心受擊判定精確縮減至 **13px**，極限貼近鋼樑邊緣也能驚險擦身而過，提供頂級電玩手感！
- **開局無敵護盾**：每次開局或重試自動賦予 **2.5 秒無敵防護電磁罩**，杜絕起跑暴斃。

### 2. 2D 多元動態閃避（左右微操 + 上下拉扯時差）
- 告別傳統急急棒單純左右死板移動的平面感：
  - **向下拉扯滯空（Pull Back / Hover）**：面對橫掃而來的三叉鋼樑，手指往下滑動，小鴨在鏡頭中向後滯空等候刀臂掠過。
  - **向前加速衝刺（Surge Forward）**：當三叉鋼樑掠出 120° 扇形開口瞬間，手指前衝穿刺，快速穿越旋轉盲區！
  - **圓弧切入（Arc Slip）**：順著三叉刀臂的旋轉角速度貼近渦輪機芯微操，兼具刺激感與高操作上限。

## 🚀 快速啟動指南

### 1. 需求環境
- [Node.js](https://nodejs.org/) (建議 v18 以上)

### 2. 啟動本機伺服器
在專案根目錄或 `duck-electric-wire/` 資料夾下：

```bash
# 方法 A: 執行啟動批次檔 (Windows)
雙擊「開啟遊戲.bat」

# 方法 B: 命令列啟動
node duck-electric-wire/server.mjs
```

### 3. 開始遊玩
以瀏覽器（建議 Chrome / Safari / Edge）開啟：
```
http://localhost:8788
```
或使用手機連接同區域網路 IP，享受最佳觸控急急棒手感！
