# 你的 IQ 有多高？（Cognitive Reasoning Lab TW）

一個以手機優先（Mobile First）、全繁體中文、80 題四選一的認知推理推估網站。
包含 2 題練習、七大認知向度、三參數 IRT（3PL）的 EAP 估算、模型參考區間、能力雷達／輪廓條、作答品質監測、續答與分享圖卡。

---

## 誠信與心理計量界線

- 本網站僅顯示「認知推理能力推估值（Beta）」，模型版本為 `TW-BETA-0.2`。
- 本題庫**未以具代表性之大型台灣成人常模校準**，不等同於 WAIS、Stanford–Binet、Raven、Mensa 或由合格臨床心理師執行之標準化心理衡鑑。
- 不得用於醫療診斷、特殊教育安置、求職篩選或法律鑑定等高風險場景。
- 所有題目、SVG 向量線稿與干擾選項皆為專案原創設計，非冷門百科或記憶背誦題，規則明確且具唯一正確解。

## 題庫配置與認知架構（精確 80 題）

| 認知向度 | 題數 | 佔比 | 包含之題型與認知操作 |
|---|---:|---:|---|
| **抽象推理（abstract）** | 16 | 20.0% | 圖形矩陣、元素加減、交替遞變、隱藏規則、新規則歸納 |
| **邏輯推理（logic）** | 14 | 17.5% | 條件邏輯、三段論、集合關係、關係排序、多條件整合 |
| **數量推理（quantitative）** | 12 | 15.0% | 數列推理、交替遞迴、模數運算、數量運算關係 |
| **空間推理（spatial）** | 10 | 12.5% | 心智旋轉、正反面鏡像、展開圖折疊、三維多步驟幾何變換 |
| **語文概念（verbal）** | 10 | 12.5% | 關係類比、結構映射、功能對應、概念分類與例外排除 |
| **工作記憶（workingMemory）** | 10 | 12.5% | 數字序列、反向回憶、符號空間位置、顏色順序、延遲操作 |
| **處理速度（processingSpeed）** | 8 | 10.0% | 視覺快速比對、缺口辨識、符號特徵計數、高相似干擾排除 |
| **總計** | **80** | **100%** | **全部 80 題四選一（A/B/C/D）唯一正解** |

### 難度分層（嚴格階梯式遞進）
1. **第 1～20 題（容易～中等）**：單一規則識別、基礎序列、直觀空間與短暫記憶。
2. **第 21～50 題（中等）**：雙重規則交叉、倒序操作、集合交集與關係對映。
3. **第 51～70 題（中高～困難）**：多條件鏈條約束、三步驟空間折疊、動態遞增記憶干擾。
4. **第 71～80 題（困難～極困難）**：高難度綜合題、隱藏維度、複合模數與極限鑑別題。

## 核心升級重點

1. **80 題四選一平衡**：
   - 正式答案位置 A / B / C / D 各精確 20 題（各 25%）。
   - 伺服器端防連續機制：同一答案選項絕不連續出現 3 次以上。
   - 題型交錯呈現，絕無連續三題相同認知操作。
2. **工作記憶時間合理化**：
   - 徹底告別「閱讀速度戰」，刺激呈現時間依資訊負荷分級延長至 **7.5 秒 ～ 15.5 秒**（簡單 7.5~8.5s、中等 9.5~11s、困難 12.5~15.5s）。
   - 採兩階段呈現（Stimulus 完整展示倒數 → 刺激消失 → 出現問題與選項），確保無認知干擾。
3. **向量 SVG 精準圖形**：
   - 所有圖形推理題均以純程式碼 SVG 繪製，無 AI 模糊或比例失真問題。
4. **計分重構（80 題 3PL IRT / EAP）**：
   - 估算能力 `θ` 範圍：-4.5 至 +4.5，四選一猜測參數 `c = 0.25`。
   - 滿分／極端反應評估：10 題以下標記「低於 70」，77 題以上標記「145 以上」。

## 開發與執行指令

### 需求
- Node.js 20+ 或 22.13+
- pnpm

### 本機開發
```bash
pnpm install
pnpm dev
```

### 執行自動化題庫驗證
```bash
pnpm test
```
- 自動檢查題數是否嚴格等於 80
- 驗證每題皆為 4 個選項且選項不重複、正解存在
- 檢查向度分布、A/B/C/D 答案各 20 題平衡
- 驗證極端反應（80 全對、80 全錯）之 EAP 數值收斂性

### 生產環境建置
```bash
pnpm run build
```
- 產出兼具 Vinext (Vite 8) 與 Next.js 16 (Turbopack) 之生產 Bundle。

### 本地生產伺服器
```bash
pnpm start
```
預設監聽於 `http://127.0.0.1:8787`。
